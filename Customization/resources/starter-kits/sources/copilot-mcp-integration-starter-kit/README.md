# GitHub Copilot MCP Integration Starter Kit

Use this kit to document and test a least-privilege MCP integration.

## Included

- A workspace MCP configuration template.
- Instructions for safe MCP usage.
- A prompt for verifying tool discovery.

## Getting started

1. Copy the `.vscode` and `.github` folders into your repository.
2. Replace the placeholder server with an approved server.
3. Review its source, permissions, network access, and data classification.
4. Start with read-only tools and document how access is revoked.

Never commit credentials or tokens to the configuration file.
