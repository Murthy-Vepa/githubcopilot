# GitHub Copilot Agent Workflow Starter Kit

Use this kit to establish a visible plan, build, and review workflow.

## Included

- Planner, Builder, and Reviewer custom agents.
- Shared instructions for handoff evidence.

## Getting started

1. Copy the `.github` folder into your repository.
2. Start with the Planner agent and review its plan.
3. Hand the approved plan to the Builder agent.
4. Run the Reviewer agent against the resulting diff.

Keep permissions narrow and require human review before consequential writes.
