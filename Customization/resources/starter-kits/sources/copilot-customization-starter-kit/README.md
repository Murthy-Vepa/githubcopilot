# GitHub Copilot Customization Starter Kit

Use this kit as a small repository-local starting point for shared Copilot customization.

## Included

- `.github/copilot-instructions.md` for durable repository conventions.
- `.github/prompts/feature-plan.prompt.md` for an explicit planning request.
- `.github/agents/planner.agent.md` for a read-only planning role.

## Getting started

1. Copy the `.github` folder into the root of your repository.
2. Replace the example conventions with rules your team can verify.
3. Run the prompt and review the generated plan before implementation.
4. Keep the files versioned and assign an owner for maintenance.

Do not add secrets, credentials, or unrestricted external tools to this kit.
