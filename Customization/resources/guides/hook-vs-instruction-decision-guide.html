Customization decision guide

Scenario-based guide

Hook or instruction?

Separate guidance that influences agent behavior from deterministic automation that runs at a defined lifecycle point.

5 scenariosControl-aware

The short answer

Choose by certainty and timing

Use an instruction

When Copilot needs context, rules, conventions, or decision guidance in relevant work.

Use a hook

When a command or policy must run deterministically before or after a lifecycle event.

Real situations

Scenario-based decisions

Scenario 1: “Always use our component library.”

Copilot needs to know the approved imports and nearby examples while generating UI code.

Choose: Instruction. Scope it to UI files and state the convention with a useful example.

Scenario 2: “Reject changes containing credentials.”

The repository must block a change even if Copilot claims the scan passed.

Choose: Hook or CI policy. Run a deterministic scanner and return actionable failure output.

Scenario 3: “Run tests after an agent edits files.”

The test command should run automatically after the relevant event.

Choose: Hook. Define the trigger, command, timeout, and failure behavior.

Scenario 4: “Explain our migration naming pattern.”

The model needs a rule and examples before proposing a migration.

Choose: Instruction. Guidance belongs in context; validation still belongs in executable checks.

Scenario 5: “The rule is advisory and exceptions are common.”

Developers need to understand the preference but may intentionally deviate with justification.

Choose: Instruction. Make the preference visible and ask for rationale rather than silently blocking work.

Before you implement

Control checklist

  • Advisory guidance is separate from enforcement
  • Hook event and ordering are documented
  • Commands have bounded permissions
  • Failures are visible and actionable
  • Instructions have the narrowest useful scope
  • Tests cover expected and failure paths
Rule of thumb: instructions influence decisions; hooks verify or perform actions at predictable lifecycle points.
