Agents

Move beyond single-turn chat. Run Copilot in agent mode to execute multi-step tasks, use tools, and integrate MCP servers autonomously.

🧩 What is Agent Mode?
💬Chat Mode (Before)
  • Single-turn request → response
  • You manually apply each suggestion
  • No tool access by default
  • No file system or terminal access
  • Context resets between turns
  • You are the execution engine
🤖Agent Mode (Now)
  • Multi-step plan → execute → verify loop
  • Copilot applies changes autonomously
  • Tools: file read/write, terminal, browser
  • Full workspace access (with guardrails)
  • Persists context across the full task
  • Copilot is the execution engine

🔌 MCP — Model Context Protocol
🔌What is MCP?

MCP (Model Context Protocol) is an open standard that lets AI models connect to external tools and data sources. Think of it as a plugin system for agents — any server that implements MCP becomes a tool Copilot can use.

🗄️ Databases 🔑 Azure Key Vault 📊 GitHub API 📁 File Systems 🌐 REST APIs ☁️ Azure Resources 📧 Email / Calendar 🔍 Search Engines 🐳 Docker / K8s + Any custom server
⚙️MCP Configuration (.vscode/mcp.json)
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y",
        "@modelcontextprotocol/server-github"
      ]
    }
  }
}
✅MCP Best Practices
  • Enable only servers you need — minimize attack surface
  • Use environment variables for secrets, never hardcode
  • Scope permissions to least privilege
  • Review tool calls before approval in sensitive contexts
  • Use local MCP servers for sensitive internal data
⚡ Agent Prompting Patterns
OUTCOME
Describe the end result, not the steps: "Add unit tests for all public methods in UserService.ts"
CONSTRAINTS
State what must NOT be changed: "Don't modify the database schema"
VERIFY
Tell agent how to confirm success: "Run the test suite and confirm 100% pass rate"
SCOPE
Limit file/folder access when possible: "Only work in src/api/"
CHECKPOINT
Ask for confirmation before destructive operations: "Ask me before deleting any files"
