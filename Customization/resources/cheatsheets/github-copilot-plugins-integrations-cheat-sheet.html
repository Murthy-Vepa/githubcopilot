Adoption checklist

Understand

List every file, script, tool, and service. Map data flow, trust boundaries, side effects, and identity.

Control

Use least privilege, require approval for high-impact actions, and isolate untrusted content.

Validate

Test normal and failure paths, scan dependencies and scripts, and measure errors and false positives.

Operate

Assign an owner and review date. Version changes and document rollback.

Red flags

SignalResponse
Unclear permissionsDo not enable until access is documented and narrowed.
Opaque downloaded scriptsInspect, scan, and test before execution.
Broad write or network accessSplit capabilities and add explicit approval.
No maintainer or update pathPrefer a maintained alternative or isolate the integration.
Rule of thumb: treat integrations as production dependencies. Trust comes from inspectable code, narrow permissions, tests, ownership, and a recovery plan.
