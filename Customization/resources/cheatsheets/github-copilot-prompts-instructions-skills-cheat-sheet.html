Customization reference

Prompts vs Instructions vs Skills

Choose the smallest customization that gives Copilot the right context, workflow, or capability.

ContextReusable tasksRepeatable methods

Choose by purpose

Prompt files

Manual task starter. Use for a focused request you run repeatedly with different inputs.

Instructions

Standing guidance. Use for standards and expectations that apply automatically within a scope.

Agent Skills

Reusable capability. Use for multi-step expertise with references, scripts, and validation.

Decision table

QuestionChooseWhy
Apply automatically to every task in a scope?InstructionsThey establish standing expectations.
Start the same focused task many times?Prompt fileIt is a reusable task template.
Several steps, references, or scripts?Agent SkillIt packages expertise progressively.
Deterministic lifecycle check?HookDo not rely on model memory for enforcement.
External system or tool?MCP serverUse a tool boundary with explicit access.

Skill

.github/skills/<name>/SKILL.md

Rule of thumb

Context belongs in instructions, a repeatable request belongs in a prompt, and a repeatable method belongs in a Skill.
