Scope first: keep repository guidance with the repository, personal preferences in personal settings, and executable capabilities behind explicit permissions and ownership.

Choose the right feature

FeatureHow to triggerBest forExample use cases
Custom instructionsAutomaticStandards, guidelines, and expectations that apply broadly.Coding standards, accessibility rules, review checklists.
Prompt filesManual: reference in chat or choose from a prompt picker.Focused tasks run repeatedly with different inputs.Generate tests, run a review checklist, draft release notes.
Custom agentsManual: select from an agent dropdown or invoke in a supported surface.Projects or processes with distinct stages and strict handoffs.Read-only auditor, security reviewer, framework specialist.
SubagentsAutomatic or direct delegation from the main agent.Complex subtasks that should run in isolation.Codebase research, test execution, dependency investigation.
Agent skillsAutomatic: Copilot selects the skill when relevant.Multi-step workflows with bundled assets loaded as needed.Deployment procedures, CI failure diagnosis, report drafting.
HooksAutomatic at configured lifecycle events.Deterministic checks or actions at a specific workflow point.Format files, approve or deny tool use, scan for secrets.
MCP serversAutomatic or by asking for a specific tool by name.Access to external tools, systems, and real-time data.Manage issues, query services, automate browser testing.

JetBrains Agent Customizations editor

In JetBrains IDEs, use the Agent Customizations editor to create and manage custom agents, skills, and reusable prompt files from the IDE. Keep repository-shared files in the project so teammates can review and version them with the codebase.

Starter patterns

Repository instructions

# .github/copilot-instructions.md
- Follow the existing repository patterns.
- Add focused tests for changed behavior.
- Keep secrets out of source and logs.

Prompt file

---
name: review-change
description: Review a focused code change
---
Review ${file} for correctness, security,
compatibility, and missing tests.

Safety and maintenance checks

Before enabling

ScopeConfirm where the customization applies.
AccessReview files, commands, network, and secrets.
OwnerIdentify the maintainer and source repository.

Before changing

TestRun representative and failure-case checks.
ReviewInspect permissions, logs, and generated changes.
RollbackDocument disable, removal, and version rollback steps.
