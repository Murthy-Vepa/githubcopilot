GitHub Copilot Hooks

Use hooks for deterministic checks, observations, and approvals at defined agent workflow lifecycle points.

Lifecycle eventsAllow or denyFail closed

Hook decisions

NeedBoundaryOutcome
Protect filesBefore file writeDeny protected paths and explain the approval route.
Block commandsBefore shell executionReject destructive or sensitive operations.
Validate changesAfter editsRun focused tests or policy checks.
Trace behaviorSession, tool, completion eventsRecord redacted structured evidence.
Require approvalBefore high-impact actionPause for an explicit human decision.

Handler contract

Input

Validate event shape, classify the operation, and treat content as data, not authority.

Decision

Return allow, deny, warn, or failure with an actionable reason.

Runtime

Bound latency and network calls. Fail closed for high-risk uncertainty.

Evidence

Log a correlation ID and decision while redacting secrets and sensitive payloads.

Test before enforcing

Behavior

AllowAllowed operation.
DenyProtected operation.
MalformedInvalid event payload.

Resilience

TimeoutHandler failure or timeout.
BypassCase and encoding variation.
ReplayRegression scenario.
Rule of thumb: instructions suggest behavior; hooks enforce or observe behavior where consistency matters.
