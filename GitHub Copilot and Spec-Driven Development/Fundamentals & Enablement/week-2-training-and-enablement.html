Learning outcomes

Prompt with intent

  • Write prompts that state role, goal, context, constraints, and output shape.
  • Decompose a complex request into smaller verifiable steps.
  • Ask for assumptions and alternatives instead of accepting the first answer.

Review generated work

  • Inspect code, tests, documentation, and references before use.
  • Ask Copilot to explain tradeoffs and identify edge cases.
  • Keep the human decision and approval visible.

Run the workflow

  • Move from problem statement to specification and plan.
  • Use an agent only with an appropriately scoped task and permissions.
  • Capture evidence of what was checked.

Preparation lab

Prepare the Week 3 story

Start with the Week 1 problem statement. Use AI-Assisted Development and Copilot to identify missing information, shape scenarios, clarify constraints, and choose the smallest useful slice for the GitHub Spec Kit walkthrough.

Preparation acceptance criteria

  • Participants can explain the SDD stages at a high level.
  • Story has a clear user outcome and bounded scope.
  • Stakeholders, constraints, and risks are identified.
  • Tools, repository access, and support paths are ready.
Facilitator emphasis

Make the workshop tactile. Participants should spend more time writing, testing, and reviewing than watching slides. Pair people across roles so “quality” includes usability, security, operations, and maintainability rather than code alone.

Required deliverables and readiness gate

Submit by Friday

  • Fundamentals and responsible-use reflection.
  • Prompt pattern or AI-Assisted Development experiment contribution.
  • Agent task brief and review checklist.
  • Prepared story with scenarios, constraints, and open questions.

Ready for Week 3 when

  • Participant can use the approved tools without setup assistance.
  • Team can explain how to challenge and verify generated output.
  • Selected story has a bounded slice and clear user outcome.
  • GitHub Spec Kit access and support arrangements are confirmed.
