GitHub Copilot and Spec-Driven Development / Week 3

GitHub Spec Kit and Agent Squad

Spend one to two focused days on the GitHub Spec Kit stages, then introduce SDD - Agent Squad roles, handoffs, and examples before Week 4 operationalizes the model for teams.

Week 3Audience: developers and delivery partnersFormat: focused workshop and Agent Squad session

Week at a glance

Days 1-2

Walk the Spec Kit stages

Use the prepared story to see how GitHub Spec Kit turns intent into structured specifications, plans, tasks, and implementation guidance.

Days 3-4

Meet Agent Squad

Explore the specialist roles, responsibilities, handoffs, checkpoints, and human decisions that shape SDD - Agent Squad.

Day 5

Prepare the handoff

Use examples and team scenarios to capture questions, ownership needs, and the operating decisions Week 4 must finalize.

Learning outcomes

Understand the stages

  • Explain what each GitHub Spec Kit stage contributes to the delivery path.
  • Recognize where SDD artifacts are created, reviewed, and revised.
  • Distinguish framework guidance from team decisions and approvals.

Understand Agent Squad

  • Describe the purpose of the specialist roles and their collaboration pattern.
  • Identify inputs, outputs, handoffs, checkpoints, and escalation points.
  • Keep human decisions and approvals visible across the workflow.

Prepare for Week 4

  • Identify the ceremonies, quality gates, and owners Week 4 must define.
  • Capture team questions, exceptions, and adoption blockers.
  • Leave a usable Spec Kit and Agent Squad handoff checklist.

Spec Kit and Agent Squad checklist

Focused workshop evidence

  • Prepared problem statement and stakeholder confirmation.
  • Stage map showing where Spec Kit supports the SDD path.
  • Specification and plan reviewed for assumptions, constraints, and scope.
  • Agent Squad role and handoff map for the representative scenario.
  • Open questions and exceptions assigned to an owner.

Quality questions

  • Which decisions still require a person to approve or clarify?
  • What assumptions did Copilot, Spec Kit, or an agent make, and were they validated?
  • Which role owns each input, output, handoff, and escalation?
  • Can another developer reproduce the reasoning from the artifacts?
  • What should Week 4 make routine in ceremonies and quality gates?
Facilitator emphasis

Keep GitHub Spec Kit focused, then make Agent Squad concrete through roles and scenarios. The goal is to give teams enough shared context to ask useful operating questions; Week 4 will turn those questions into ceremonies, quality gates, and ownership.

Required deliverables and readiness gate

Submit by Friday

  • Completed GitHub Spec Kit stage walkthrough for the bounded story.
  • Reviewed specification, plan, and task path.
  • Agent Squad role, scenario, and handoff checklist.
  • Operating-model backlog covering ceremonies, gates, ownership, and support.

Ready for Week 4 when

  • Team understands the Agent Squad model without treating it as fully operational yet.
  • Spec Kit scope stayed within one to two focused days.
  • Open blockers and exceptions have an owner and next action.
  • Team has clear questions for the Week 4 SDD - Agent Squad operating review.
