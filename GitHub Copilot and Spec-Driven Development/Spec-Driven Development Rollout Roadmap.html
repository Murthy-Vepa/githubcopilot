GitHub Copilot, AI-Assisted Development and Spec-Driven Development

Spec-Driven Development Rollout

Establish Spec-Driven Development using Agent Squad as the standard engineering practice across the organization.

4-week adoption program Audience: development teams, product owners and delivery partners

Rollout at a glance

Week 1 / Foundation and Standards

Set the standard

Week 1 (July 27 - July 31)
  • Finalize SDD process and expectations.
  • Define when SDD is required and document exceptions.
  • Approve requirements, specifications, plans, and task templates.
  • Define traceability and DoR / DoD expectations.
  • Launch support channels and office hours.
Milestone: Standards, templates, and support model approved.
Open Week 1 guide ↗
Week 2 / Fundamentals and Enablement

Build the foundation

Week 2 (August 3 - August 7)
  • Deepen Fundamentals, responsible use, and Copilot mental models.
  • Practice AI-Assisted Development, prompt engineering, and context management.
  • Explore Copilot modes, agents, tools, and review checkpoints.
  • Introduce SDD concepts and prepare the selected practice story.
  • Validate repository, access, and tool readiness with support available.
Milestone: Teams understand the fundamentals, can use Copilot responsibly.
Open Week 2 guide ↗
Week 3 / GitHub Spec Kit and Agent Squad

Explore the delivery path

Week 3 (August 10 - August 14)
  • Spend one to two focused days learning the GitHub Spec Kit stages.
  • Connect the Spec Kit stages to the team's SDD workflow.
  • Introduce SDD - Agent Squad roles, responsibilities, and handoffs.
  • Use the remaining time for Agent Squad examples, scenarios, and questions.
  • Capture a reusable specification, plan, task path, and Agent Squad handoff checklist.
Milestone: Teams complete a GitHub Spec Kit walkthrough, focused on the Agent Squad.
Open Week 3 guide ↗
Week 4 / Team Adoption & Operationalization

Make it routine

Week 4 (August 17 - August 28)
  • Integrate SDD into backlog refinement and sprint planning.
  • Apply it to reviews, testing, and delivery ceremonies.
  • Validate end-to-end traceability.
  • Capture lessons learned and team feedback.
  • Establish ongoing adoption reporting.
Milestone: SDD incorporated into normal team delivery.

What changes for teams

From prompt to process

Copilot and agents support a defined engineering workflow with clear intent, context, constraints, and review points.

From output to evidence

Requirements, plans, tasks, code, tests, and reviews remain connected so teams can explain how work was produced.

From experiment to operating model

SDD - Agent Squad becomes a repeatable team practice with ownership, coaching, governance, and measurable adoption.
