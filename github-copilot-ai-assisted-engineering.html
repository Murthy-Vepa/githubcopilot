05 / Vibe Coding vs AI-Assisted Development Working Patterns

Compare the working patterns.

Vibe Coding

Broad prompts, rapid experimentation, and larger generated outputs.

Meaning + control

Start with the result

AI generates much of the code from broad prompts. The user checks whether the app appears to work, then prompts again.

Human role

Steer the builder

AI fills in technical details while the human guides it through goals, natural language, feedback, and corrections.

Prompt + plan

Explore conversationally

Prompts are broad, and the plan forms during repeated prompting and feedback.

Review + output

Validate the visible behavior

Less coding knowledge is needed; AI may generate large chunks such as full screens, features, or small apps.

AI-Assisted Development

Focused tasks, developer control, and deeper technical review.

Meaning + control

Start with the code and requirements

AI helps with specific coding tasks while the developer controls logic and checks that changes are correct and reliable.

Human role

Direct the helper

AI drafts, explains, suggests, or speeds up selected work while the developer reviews output and makes major decisions.

Prompt + plan

Work from clear constraints

Prompts are narrower, and the developer starts with requirements, constraints, and expected behavior.

Review + output

Check logic, tests, and fit

Enough technical knowledge is needed to judge correctness, reliability, and security. AI produces smaller, reviewable tasks.

Choose Vibe CodingWhen speed, discovery, and a disposable prototype matter most.
Choose AI-Assisted DevelopmentWhen correctness, maintainability, security, and review matter most.

08 / Well-Structured Prompt

Well-structured prompts produce clearer, more relevant results.

A well-structured prompt is like a well-organized document: it has clear sections, logical flow, and purposeful organization.

•

1. System Message

Set the role, behavior, and overall guidelines for the AI.

Example“You are a helpful assistant that provides accurate, concise, and reliable information.”
•

2. Task Instruction

Clearly state what you want the model to do.

Example“Summarize the key benefits of renewable energy in bullet points.”
•

3. Context / Input

Provide the background information or input data the model needs.

Example“Here is an article about renewable energy technologies: <paste article or data>”
•

4. Constraints

Specify rules, limitations, assumptions, or boundaries to follow.

Example“Keep it concise (max 150 words). Focus on factual information. Do not include opinions.”
•

5. Output Format

Define the desired structure or format of the response.

Example“Respond in markdown with a title and bullet points.”
Why it mattersA well-structured prompt reduces ambiguity, improves accuracy, and helps AI generate better, more relevant results.
Best practiceFollow the structure, be specific, and provide enough information for the best outcome.
Better Prompts.
Better Results.

09 / Prompting Techniques

Choose the right technique for the task.

Experiment with different prompting techniques, combine what works, and refine your prompts for clearer, more useful results.

Basic techniques

1

Zero-ShotDirect instructions

Give the model a task or question without examples.

Use whenthe task is straightforward and you want a quick answer.
2

Few-ShotLearn from examples

Provide a few examples to show the model what you want.

Use whenyou need higher accuracy or the task has specific patterns.

Advanced techniques

3. Chain-of-ThoughtStep-by-step reasoning

Ask the model to think through a problem before answering.

ExampleSolve the problem step by step.

4. Self-ConsistencyMultiple reasoning paths

Generate multiple paths and select the most consistent answer.

ExampleTry several approaches, then compare.

5. Tree-of-ThoughtsStructured exploration

Explore branches and evaluate different possibilities.

ExampleConsider pros and cons of each option.

6. ReActReasoning + acting

Combine reasoning with actions using tools or an environment.

ExampleSearch, reason about findings, and report.

7. Prompt ChainingMulti-step workflows

Break a complex task into steps and chain prompts together.

ExampleExtract data, analyze it, then generate a report.

Context Window & Token Budgeting

Make every token count. Better context. Better answers. Lower cost.

The context window (finite token budget)
Total context windowExample: 128,000 tokens
☰

●
User contextProfile, preferences, memory~1,000-3,000
⌕

HistoryTurns and summaries~2,000-20,000
