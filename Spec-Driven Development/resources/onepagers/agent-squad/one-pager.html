⚡ Invoking the Orchestrator
💬Simple invocation
// In Copilot Chat panel
@orchestrator "Add CSV export to the
TodoApp. Users click Export on the
Index page and download a CSV of
all their todos."

// Orchestrator will:
// 1. Route to @planner → spec.md
// 2. Wait for your approval
// 3. Route to @coder → implement
// 4. @tester → @reviewer → @security
// 5. Open PR with all reports
🔄Rework loop example

If a downstream agent finds a problem, the orchestrator automatically routes back to the right agent without requiring human intervention.

// Security agent flags SQL injection
@security-review: FAIL
Found: raw string concat in
         TodoRepository.cs:47

// Orchestrator auto-routes back
@orchestrator: Routing to @coder
// Coder fixes, tester re-runs
// Security re-approves → PR opens
✅Rework loops run automatically. You only get notified at human gates — approve or reject, nothing else needed.
🔍 Specialist Agent Deep Dives
🔐Security Review Agent
ChecksOWASP Top 10: injection, broken auth, IDOR, XSS, CSRF, secrets in code
OutputStructured report: severity, file:line, remediation guidance
BlocksPR cannot open until all CRITICAL findings are resolved
📊SRE / Observability Agent
ChecksStructured logging on all paths, health check endpoint, error handling completeness
AddsMissing ILogger calls, /health endpoint if absent
OutputRunbook snippet for on-call engineers attached to PR
📝Document Writer Agent
GeneratesAPI reference from controller/service signatures
UpdatesCHANGELOG.md with feature description and PR link
UpdatesUser guide sections that reference changed functionality
