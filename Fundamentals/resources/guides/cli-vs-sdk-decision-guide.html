CLI or SDK?

Choose between an interactive command-line workflow and a programmatic integration when you want to use Copilot capabilities in your work.

5 scenariosBuild-aware

The short answer

Choose by interaction and ownership

Use the CLI

When a person or script needs a direct terminal workflow, fast iteration, and command-line output.

Use the SDK

When an application needs sessions, orchestration, permissions, events, and a product experience.

Real situations

Scenario-based decisions

Scenario 1: “Help me inspect and modify this repository.”

A developer is at a terminal and will review commands, diffs, and tests directly.

Choose: CLI. Keep the workflow interactive and validate the resulting repository state.

Scenario 2: “Build a deployment-readiness assistant.”

A web application needs sessions, approved tools, user identity, and a structured result.

Choose: SDK. The application must own orchestration, permissions, and user-facing behavior.

Scenario 3: “Run the same analysis in a scheduled job.”

The job can invoke a command, capture output, and fail the run based on a validation result.

Choose: CLI first. Use the simplest automation boundary; move to SDK when application-level state or control is needed.

Scenario 4: “Add approvals before external write actions.”

The system needs a user approval screen, an audit trail, and policy-aware tool routing.

Choose: SDK. These are application responsibilities, not just terminal command concerns.

Scenario 5: “We do not yet know whether users want this.”

The team needs evidence before investing in an integrated product.

Choose: CLI prototype. Prove the workflow, capture inputs and outputs, then define an SDK boundary if adoption justifies it.

Before you choose

Delivery checklist

  • Primary user and interaction are known
  • Local versus application context is explicit
  • Credentials and permissions have an owner
  • Output and failure behavior are testable
  • Automation has bounded side effects
  • SDK integrations have session and dependency plans
Rule of thumb: use the CLI to operate Copilot, and the SDK to build Copilot into an application.
