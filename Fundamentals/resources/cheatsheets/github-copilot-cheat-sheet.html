🔐 Security Rules
NEVER share with Copilot
API keys · passwords · connection strings · PII · proprietary algorithms
Enterprise policy (MetLife)
Copilot Business — data NOT used for training · Public code filter ON
Always review output
Treat AI suggestions as a first draft. You own the code.
