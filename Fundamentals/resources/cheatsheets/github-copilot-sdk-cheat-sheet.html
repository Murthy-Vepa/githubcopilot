GitHub Copilot SDK

Embed Copilot's agent runtime in Node.js, Python, Go, Rust, .NET, or Java applications. The SDK handles sessions, planning, tool invocation, streaming, and the CLI runtime connection.

The core lifecycle

CopilotClient->createSession->sendAndWait->assistant response->stop
import { CopilotClient } from "@github/copilot-sdk";

const client = new CopilotClient();
const session = await client.createSession({ model: "auto" });
const response = await session.sendAndWait({ prompt: "What is 2 + 2?" });
console.log(response?.data.content);
await client.stop();

Sessions and streaming

Session operations

createSessionStart a new conversation.
sendQueue a message and return immediately.
sendAndWaitSend a message and wait until idle.
onSubscribe to all or specific events.
abortStop the current message.
disconnectRelease the session; data can remain resumable.
resumeSessionContinue an existing session by ID.

Stream response deltas

const session = await client.createSession({
  model: "auto",
  streaming: true,
});

session.on("assistant.message_delta", event => {
  process.stdout.write(event.data.deltaContent);
});
session.on("session.idle", () => console.log());

await session.sendAndWait({ prompt: "Tell me a joke" });

Custom tools and permissions

Define a tool

import { defineTool } from "@github/copilot-sdk";

const getWeather = defineTool("get_weather", {
  description: "Get weather for a city",
  parameters: {
    type: "object",
    properties: { city: { type: "string" } },
    required: ["city"],
  },
  handler: async ({ city }) => ({
    city, condition: "sunny", temperature: "72F",
  }),
});

const session = await client.createSession({
  model: "auto", tools: [getWeather],
});

Permission decisions

approve-onceAllow one request.
approve-for-sessionRemember approval for this session.
approve-for-locationPersist approval for a project location.
rejectDeny and optionally return feedback.
no-resultLeave a pending request for another client.
const session = await client.createSession({
  onPermissionRequest: async request => {
    if (request.kind === "shell")
      return { kind: "reject", feedback: "Shell denied" };
    return { kind: "approve-once" };
  },
});

const session = await client.createSession({

Production checklist

Secure the boundary

ApproveUse a custom permission handler for shell, write, MCP, and custom tools.
SecretsUse environment variables; never put tokens in prompts or source.
RuntimeUse loopback for local servers; protect remote headless servers.

Observe the runtime

const client = new CopilotClient({
  telemetry: {
    otlpEndpoint: "http://localhost:4318",
  },
});

// Or export JSONL traces:

Keep the app healthy

LifecycleStop the client and disconnect sessions during cleanup.
StreamingHandle deltas and wait for session.idle.
ErrorsCatch SDK errors and define retry, skip, or abort behavior.
